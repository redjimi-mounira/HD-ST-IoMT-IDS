# HD-ST-IoMT-IDS
Official implementation of HD-ST (Hybrid Dual-Stream Transformer), a novel AI-based intrusion detection system for the Internet of Medical Things (IoMT). The framework combines dual-stream Transformer encoders, bidirectional cross-attention, and explainable AI (SHAP) for accurate, low-latency, 19-class attack detection on the CICIoMT2024 dataset.
# HD-ST-IoMT-IDS

## Hybrid Dual-Stream Transformer for IoMT Intrusion Detection

HD-ST is an AI-based intrusion detection system designed to enhance cybersecurity in Internet of Medical Things (IoMT) environments.

The proposed approach combines a dual-stream Transformer architecture with Cross-Attention to detect and classify cyberattacks using network traffic and device profiling features.

### Key Features
- Dual-Stream Transformer architecture.
- Bidirectional Cross-Attention.
- Multiclass intrusion detection.
- Imbalanced data handling.
- Explainable AI using SHAP.
- Low-latency classification.

### Dataset
CICIoMT2024 – 19 classes, including benign traffic and 18 attack classes.

### Performance
- Accuracy: 97.75%
- Detection Rate: 98.73%
- Macro-F1: 75.22%
- Macro-AUC: 0.9768
